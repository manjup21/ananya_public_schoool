# Ananya Public School ERP API

Express + PostgreSQL API for Ananya Public School.

- Database name: `ananya_public_school_erp`
- School branding env: `SCHOOL_NAME=Ananya Public School`
- Auth cookie: `ananya_erp_token`
- Default local port: `5025`

```bash
cp .env.example .env   # if needed
npm install
npm run dev
```

API: `http://localhost:5025` · Health: `/api/health`
